# 夫妻暖心记账本
专为情侣/夫妻打造私密家庭记账网站，带密码登录，本地存储账单，GitHub Pages 免费在线使用。

## 功能清单
1. 密码锁登录，可自由修改家庭密码（默认1314520）
2. 收入/支出完整分类
    收入：工资、奖金、兼职、红包、其他收入
    支出：餐饮、住房、交通、购物、医疗、人情、娱乐、育儿、其他
3. 月度统计：总收入、总支出、当月结余、月度预算设置
4. 支出分类饼图可视化，直观看清钱花在哪
5. 账单增删、日期+备注记录
6. 账单数据导出备份 / 导入恢复（JSON文件）
7. 一键清空所有账单
8. 温馨粉色情侣治愈UI，移动端自适应
9. 所有数据保存在浏览器本地 localStorage，不上传服务器

## 使用教程
1. 下载仓库全部4个文件放在同一文件夹
2. 本地打开 index.html 输入密码 1314520 进入记账
3. 设置本月预算，日常添加收支账单
4. 定期导出JSON备份，换浏览器/设备时导入恢复

## GitHub Pages 部署步骤
1. 打开 GitHub，新建仓库，命名 couple-account
2. 上传 index.html home.html style.css app.js README.md 全部文件
3. 仓库右上角 Settings → Pages
4. Source 选择 Deploy from a branch
5. 分支选 main，文件夹选择 /(root)，保存
6. 等待1分钟，生成公开访问链接，夫妻两人都可以打开使用

## 注意事项
1. 数据存在当前浏览器，清除缓存会丢失，务必定期导出备份
2. 多人共用链接：每台设备数据独立，需要互相导入备份同步账单
3. 密码仅本地生效，更换浏览器需要重新设置密码
